## 📱 User Experience

### First-Time User Flow
1. See Auth screen with 🎭 StageEgo branding
2. Click "Start as Guest"
3. Choose coaching mode (6 options with clear descriptions)
4. Add API key (test it to validate)
5. Get real coaching from AI
6. Can switch coaches anytime
7. Sessions saved locally

### Coaching Philosophy
- **Honest feedback** (not participation trophies)
- **Specific suggestions** (not vague advice)
- **Actionable steps** (immediately usable)
- **Encouraging tone** (supporting growth)
